# Krypton for Windows

**The home of Krypton's Windows downloads and releases.**

Krypton is a Windows browser built around organized tabs, workspaces and a clean
interface. Built on Helium, it brings together browsing ideas familiar to Arc
and Zen Browser users.

## About the browser

- **Keep browsing organized:** workspaces, tab folders and a sidebar for the
  sites you use every day.
- **Make room for your pages:** flexible layouts that let you choose how much
  of the browser interface is visible.
- **Make it feel like yours:** themes and appearance choices for a more
  personal browsing space.

For people exploring an Arc browser alternative on Windows, enjoying Zen
Browser's approach to tabs, or looking for a different interface built on
Helium, Krypton offers its own take on those familiar workflows.

Krypton is an independent project in active development. Its browser and
interface are developed in the [Krypton](https://github.com/perpetus/Krypton)
and [KryptonUI](https://github.com/perpetus/KryptonUI) repositories.

## Get Krypton

- [Web installer](https://github.com/perpetus/krypton-windows/releases/latest): a smaller download that fetches the current browser during setup.
- [Offline installer](https://github.com/perpetus/krypton-windows/releases/latest): includes everything needed to install without an internet connection.

Close any open Krypton windows before installing. Existing browser profiles are
kept when updating.
