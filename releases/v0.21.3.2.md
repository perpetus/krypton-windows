# Krypton 0.21.3.2 — Native UI fixes

**Download `KryptonSetup-0.21.3.2-offline-x64.exe` for installation.**
Close all Krypton windows before running setup.

This stable maintenance release includes **KryptonUI 0.1.1.1** and keeps
**Chromium 157.0.8103.38**. The release marker advances to 0.21.3.2 so the
signed updater can offer it to existing installations. The marker is applied
to staged browser copies; executable code sections and the Chromium engine
version remain unchanged by that operation. No Chromium rebuild was required.

Changes include:

- Corrected the Windows taskbar policy used with native caption controls. The
  Windows App SDK marker that kept the taskbar above a fullscreen browser is
  suspended while Krypton's title bar is attached; Chromium retains ownership
  of fullscreen sizing, activation, and exit behavior.
- Updated focus and popup cleanup for horizontal downloads, Library, and media
  controls, including delayed hover refresh and closing-state cleanup.
- Corrected stale Glance page bindings that could hide the normal page surface
  when an inactive controller was removed or replaced.
- Added an active outline for Essential tabs in vertical and horizontal layouts.
- Extended gradient banding mitigation across theme-backed surfaces and added
  the Acrylic Thin menu material option.

Release builds, archive integrity, embedded package signatures, prerequisite
signatures, versions, and packaged UI hashes are checked during preparation.
The release includes a signed full update package and a signed source snapshot
containing the current working-tree changes and upstream revision records.

Automated tests, installation/upgrade checks, screenshots, performance sessions,
and long-session native interaction checks were not run for this release.
Fullscreen, hover/menu behavior, and Glance acceptance remain manual.
No binary delta is included.

Windows 10 version 1903/build 18362 or newer and an AVX2-capable x64 processor
are required. Keep a backup of important browser data.
