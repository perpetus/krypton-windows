# Krypton 0.20.3.1 — automatic updater test

This build updates Krypton to **Helium 0.20.3.1** and **Chromium 156.0.8078.79**.
It provides a newer native browser version for testing an update from
`0.20.1.1` through Krypton's signed GitHub updater.

**For a manual installation, download `KryptonSetup-0.20.3.1-offline-x64.exe`.**
The setup contains the browser, the current native `krypton_ui.dll`, and the
required Microsoft runtime installers.

This release includes Windows compiler-compatibility fixes found during the
upgrade. The final browser rebuild emitted no compiler warnings. Signature,
archive, and packaged UI checks passed; automated test suites and visual checks
remain deferred.

The updater uses the signed full package for this release. Delta generation
was unavailable for the `0.20.1.1` base, so no delta asset is offered.

## Test the automatic update

1. Start your installed Krypton `0.20.1.1`.
2. Let the updater download and verify the new package. You can view its status
   in Krypton's About settings.
3. Close all Krypton windows after the download finishes. The updater installs
   once the browser exits and its files are unlocked.
4. Reopen Krypton and confirm the version is `0.20.3.1`.

This release is listed as GitHub's latest stable release so the installed
updater can find it. It remains a testing build; automated test suites and
visual acceptance are deferred to the user.

Updates use signed metadata, a pinned release key, and payload hashes. The
updater does not terminate the browser to replace locked files. The `.7z`
assets are updater payloads and are not needed for manual setup.

The x64 build requires Windows 10 version 1903 or newer and the instruction
features checked by setup, including AVX2.
