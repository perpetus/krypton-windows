# Krypton 0.21.3.1 — Chromium 157

**Download `KryptonSetup-0.21.3.1-offline-x64.exe` for installation.**
Close all Krypton windows before running setup.

This regular release upgrades the browser to **Chromium 157.0.8103.38** and
**Helium 0.21.3.1**. The offline installer includes the matching Chromium 157
native setup, KryptonUI **0.1.1.0**, and the required Microsoft runtime installers.

The browser also includes the fix for the captured edge-click crash: when a
mouse press reaches Chromium while the native address-bar anchor is hidden or
unavailable, the bounds query now returns an empty rectangle instead of
triggering a fatal check.

The existing horizontal and vertical layouts, Library and media controls,
search appearance options, and hover-preview lifecycle changes are retained.
Long-session hover/menu behavior and the previously reported Glance issues
still require manual verification.

The browser and matching native setup have been built. Release signatures,
archive integrity, embedded browser/setup versions, and packaged UI hashes
were checked during installer preparation. Automated tests, screenshots,
performance sessions, live upgrade checks, and clean-machine installation were
not run for this release. Visual verification remains manual.

The release includes a signed full update package and a signed source snapshot.
Installed browsers can receive it through Krypton's normal updater after the
browser closes. No binary delta is included.

Windows 10 version 1903/build 18362 or newer and an AVX2-capable x64 processor
are required. Keep a backup of important browser data.
