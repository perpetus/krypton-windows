# Krypton 0.20.1.1 — Windows testing release

The first Windows release in this repository is ready for hands-on testing.

**To install, download `KryptonSetup-0.20.1.1-offline-x64.exe` below.** Close Krypton before running setup. This is the complete offline installer; the update `.7z` is not needed for manual installation.

## Included

- Krypton's native Windows interface, workspaces, folders, and Chromium address-bar suggestions.
- Chrome Web Store extension support.
- Chromium **156.0.8078.47**, with Krypton browser version **0.20.1.1**.
- The native `krypton_ui.dll`, settings artwork, and runtime bootstrap.
- Compatibility checks and bundled Microsoft runtime installers.
- A separate updater and uninstaller, including Windows file descriptions and version information.
- Signed release metadata and payload verification.
- Update checks handle a repository with no stable release yet without showing a download error.

The setup fixes native archive unpacking error 57. Same-version repairs are supported with the browser closed. It also recognizes the older `1.16.0.1`/Chromium 152 numbering when the signed package contains a newer Chromium engine.

## Before installing

This x64 build requires Windows 10 1903 or newer and an AVX2-capable processor with the additional features checked by setup. Windows may show a SmartScreen or unfamiliar-publisher prompt because these files do not yet have a Microsoft-trusted publisher certificate. Detached Krypton release signatures and checksums are included.

This is an early testing release. Keep a backup of important browser data and report problems through [Issues](https://github.com/perpetus/krypton-windows/issues). Clean-machine installation, end-to-end updates, and same-version UI replacement still need hands-on acceptance verification. Automated tests for the new installer/update changes have been deferred.

This GitHub release is marked **prerelease**, so the stable automatic updater will not offer it. Install the setup manually to try it.
