# Krypton 0.20.3.3 — native Windows UI update

**Download `KryptonSetup-0.20.3.3-offline-x64.exe` for installation.**
Close Krypton before running setup. This regular release includes the updated
native UI DLL **0.1.1.0**, the browser, and required Microsoft runtime installers.
Chromium remains **156.0.8078.79**.

Changes include:

- Horizontal tabs place the New Tab button after the last tab, with Library,
  downloads, and media controls beside the app menu.
- Chrome rows follow caption-button height in horizontal and vertical modes.
- Search supports floating and URL-bar-attached layouts, a matching attached
  radius, and an optional menu backdrop.
- Download and media hover previews use current pointer geometry, guard against
  stale close/reopen callbacks, and respect menus and text editors owning input.
- Site tools open by their toolbar button, with the Zen tools icon, and the
  duplicate extension button is removed from the address bar.

The release marker **0.20.3.3** is applied to release strings and version
resources in a separate staging copy. Chromium's executable code sections and
engine version are unchanged; the original browser build is preserved and
Chromium was not rebuilt for this release. The UI DLL is independently versioned.

Release signatures, package integrity, staged code-section hashes, and the
packaged UI DLL hash are verified during preparation. Automated tests,
screenshots, and performance sessions remain deferred at the maintainer's
request. Long-session hover/menu behavior and reported Glance crashes still
require manual verification.

The signed full update package supports the normal installed-browser updater.
No binary delta is included. Windows 10 version 1903/build 18362 or newer and
an AVX2-capable x64 processor are required.
