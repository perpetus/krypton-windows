## Krypton 0.21.3.5

- Improved tab and menu hover handling across native popup surfaces.
- Improved focus handoff for Library, downloads, media controls, and Boost.
- Updated the native Windows interface to Windows App SDK 2.6.5.
- Based on Chromium 157.0.8103.50 and Helium's Windows build layers.

Choose the web installer for a smaller initial download, or the offline
installer for the complete package. Existing installations receive this update
through Krypton's automatic updater.
