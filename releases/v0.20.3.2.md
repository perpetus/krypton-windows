# Krypton 0.20.3.2 — Windows UI improvements

This maintenance release updates Krypton's native Windows interface while
keeping Chromium **156.0.8078.79** and the existing Helium 0.20.3 engine build.

**For manual installation, download `KryptonSetup-0.20.3.2-offline-x64.exe`.**
The setup includes the browser, the updated `krypton_ui.dll`, and the required
Microsoft runtime installers.

Changes include:

- Smoother workspace gradients with subtle dithering, including with glass off.
- Theme-aware loading glow and progress colors, with brighter colors in dark mode.
- Theme-picker behavior aligned with Zen, including lighter colors at the edge.
- Rounded compact-mode surfaces, corrected workspace icons, and Library hover polish.
- Media-hover stability fixes and removal of the tab loading-status glyph.
- Theme-editor card, arrows, slider alignment, and native rendering crash fixes.

The UI Release build is current. This release reuses the compiled browser engine
and advances its release strings and version resources in a separate staging
copy; executable code sections and the Chromium engine version are unchanged.
Release signatures, archive integrity, and the packaged UI DLL hash are checked
during preparation. Automated tests and screenshots remain deferred at the
maintainer's request; visual verification is manual.

Existing installations use Krypton's signed GitHub updater. The browser must
close before an update can replace its files. A full update package is always
available. Delta generation was unavailable for the `0.20.3.1` base, so this
release uses the signed full update package.

Crashpad remains available for local crash capture. Sentry integration and
automatic crash uploads are not included in this release.

Windows 10 version 1903/build 18362 or newer and an AVX2-capable x64 processor
are required. This is an early testing release; keep a backup of important
browser data.
